# HC PMS AI Agent 设计

状态: 后续设计, Batch 1 不包含模型接入, RAG, Agent 工具或 AI 自动化. 本文不宣称已经存在 AI 后端. AI 相关外部服务, 模型, 部署位置和数据处理合同需要后续选择.

## 目标与边界

AI 帮助项目成员定位证据, 汇总进展, 识别缺失交付物和起草行动. 项目状态, 审批决定, 成本事实和外部承诺由受控业务接口维护. AI 不直接写数据库, 不绕过 BPM, 不代替签核人批准 Gate, 不自行接受风险或承诺客户交期.

## 分阶段能力

| 能力 | 输入 | 输出 | 放行条件 |
|---|---|---|---|
| 项目问答 | 有权访问的项目对象和文件版本 | 带来源引用的事实答复 | 服务端检索范围校验, 无证据明确未知 |
| 进展摘要 | 状态, 计划版本, 执行快照和问题 | 分离事实, 推断和建议的摘要 | 指标可复算, 时间戳可见 |
| 交付缺口检查 | 模板要求, 当前证据和 Gate 条件 | 缺失项列表和理由 | 使用规则引擎结果, 不让模型修改必需条件 |
| 会议行动项 | 授权纪要 | 负责人/期限/内容草稿 | 人工逐项确认后调用正常任务接口 |
| URS 辅助 | 授权需求版本和设计/测试证据 | 候选分类和追踪链接 | 人工接受关系, 保留 AI 来源 |
| 风险辅助 | 延期, 缺件和偏差事实 | 候选风险及缓解建议 | 明确推断, 不自动接受风险或关闭问题 |
| 变更影响辅助 | 基线差异和依赖图 | 受影响对象及依据 | 确认前只读, 不自动发布新基线 |

## 调用结构

客户端携带当前项目上下文发起对话. AI 编排服务从服务端登录态取得 user_id, 计算授权项目/对象集合, 然后调用只读业务工具或检索索引. 模型不接受客户端自报的角色和任意项目范围. 每次工具调用重新鉴权, 成员撤销后不得沿用旧会话权限.

推荐先提供窄工具: `get_project_summary`, `list_project_tasks`, `get_gate_evidence`, `search_project_documents`, `get_cost_snapshot` 等. 每个工具有输入 schema, 固定参数上限, 服务端授权, 字段白名单和执行审计. 财务工具需要额外财务权限. 不暴露自由 SQL, 任意 HTTP 请求, 文件系统读写或不受限 shell.

后续写工具先生成 `ActionProposal`, 包含业务对象 ID, 当前版本, 目标操作, 字段差异, 依据, 风险及有效期. 用户确认后再次校验权限/对象版本, 再调用普通业务服务. 若对象已改变, proposal 失效并要求重新查看差异. 原业务需要审批时继续进入 BPM, 人工确认不能跳过它.

## 证据与检索

索引最小单元包含 tenant/project_id, object_type, object_id, version_id, source_uri, content_hash, security_label, effective_at 和 indexed_at. ACL 过滤必须发生在召回之前及返回之前, 不能先跨项目召回再仅靠提示词要求隐藏内容. 检索缓存以授权范围和索引版本隔离; 原文权限失效时对应摘要与缓存一并失效.

每条答复中的关键业务事实引用到对象或文档版本. UI 显示来源标题, 版本和时间, 点击引用重新校验权限. 无来源或互相冲突时明确指出, 不把模型推断包装成系统记录. 文档内容属于不可信输入; 其中要求忽略规则, 发送数据或执行指令的文本不具有工具授权能力.

结构化数字从确定性服务获取. 模型可以解释成本差异, 不能自算正式费用分摊后直接入账. 概算和核算必须标出口径, 币种, 期间与版本, 防止以含糊数字作项目决策.

## 数据与运行控制

模型连接在服务端管理, 密钥不进入前端构建产物. 外发数据按最少必要原则裁剪. 项目文档和财务内容是否可发送外部模型取决于已批准的数据处理策略; 本设计不假设默认允许. 记录 prompt 模板版本, model 标识, 工具摘要, 引用, proposal 和确认事件, 日志对敏感字段脱敏.

提供请求超时, token/费用配额, 并发限制, 重试次数和取消. 模型不可用时核心项目管理仍正常. AI 摘要显示生成时间和依据版本, 过期结果不能作为 Gate 当前证据.

## 验收与评估

使用合成项目和获准脱敏用例建立基准集. 至少覆盖:

- 同项目正确检索, 跨项目诱导越权, 成员撤权后的历史对话和引用访问.
- 无相关证据, 冲突版本, 过期执行数据和零分母财务问题.
- 恶意文档提示注入, 要求自由 SQL/任意联网, 伪造审批或角色.
- 写入 proposal 的取消, 重复确认, 超期确认和版本冲突.
- 正常工具失败, 超时, 限流及部分结果, 核心业务可继续使用.

评估分别统计事实正确性, 引用支持率, 关键事实缺失率, 越权阻断, 操作可恢复性, 响应时间和费用. 阈值由试点业务与安全负责人批准后冻结. 不在没有测量时宣称准确率或生产可用性.
