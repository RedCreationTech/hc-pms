# HC PMS UI 与交互设计

状态: 目标交互设计及 Batch 1 页面合同. 使用现有 ClojureScript/Reagent/Ant Design 6 管理端, 沿用模板登录, 布局, 动态菜单和权限约定. 后续页面只作为设计, 不显示为已上线功能.

## 信息架构

首批入口为 PMS 下的项目中心, 以及权限内的项目概览. 项目列表进入详情后可查看基本信息, 项目结构, 项目成员及状态操作. 后续按批次增加计划与 Gate, 需求与文档, 执行与偏差, 财务, 集成管理和 AI 助手.

未实现模块不做可点击的空页面. 若为演示展示未来模块, 清晰标注规划中并禁用操作, 避免用户误以为已保存或已提交.

## 首批页面

| 页面/区域 | 数据与操作 | 交互要求 |
|---|---|---|
| 项目列表 | 编码, 名称, 负责人, 状态, 日期; 查询/新增/编辑/详情 | 服务端分页与范围过滤; 空状态提供有权限的创建入口 |
| 项目表单 | 编码, 名称, 项目类型, 负责人, 部门, 日期, 客户和合同编号 | 必填提示靠近字段, 日期逻辑即时提示; 服务器校验为最终准则 |
| 项目详情 | 当前项目基本信息, 状态, 可执行动作 | URL 可刷新; 未授权统一拒绝, 不先渲染旧项目内容 |
| 结构树 | 主/子/单机节点, 名称, 编码和父子关系 | 按合法节点类型提供新增按钮; 首批无子节点编辑/删除/迁移 |
| 成员管理 | 用户, 项目角色/职责, 成员列表 | 只能选有效账号; 已存在成员调整角色; 首批没有移除入口 |
| 状态操作 | 立项, 进入计划, 取消 | 操作前说明目标状态; 取消采集原因; 提交期间防重复 |
| 项目概览 | 可见项目总数与状态分布 | 统计范围与列表一致, 点击指标沿同一筛选条件下钻 |

首批数据以实际实现为准, 不在页面显示伪造的齐套率, 成本, 逾期率或进度百分比. 未有相应业务记录时使用空值/未启用, 不用 0 代替未知.

## 关键流程

### 创建项目

用户从项目列表新建, 填写基础信息并提交. 成功后显示具体项目名称和编码, 更新列表并可进入详情. 失败保留表单输入, 将字段错误定位到对应控件, 不用全局弹窗覆盖全部业务错误. 编码冲突给可修正提示.

### 建立结构和团队

从项目详情选择父节点新增子节点. UI 仅展示合法类型, 服务端仍检查关系及项目归属. 创建成功更新当前树分支, 不导致选择跳到另一项目. 成员添加或角色调整成功后刷新成员和可用操作范围.

### 推进状态

状态按钮由当前状态及权限决定. `draft -> initiated -> planning` 是首批闭环. planning 页面明确说明后续执行需要计划/Gate模块; 不提供会成功进入执行的假按钮. 即使手动构造请求, 服务端也返回409并保留原状态.

### 取消与后续归档

首批提供取消, 不提供项目删除或归档. 取消确认显示项目编码, 名称和状态变化并采集原因. 后续归档与成员撤销使用独立命令, 展示影响范围并保留审计. 不使用含糊的确定按钮描述不可恢复业务动作. 不以隐藏按钮代替接口权限.

## UI 状态与可用性

- Loading: 表格/详情骨架或加载态, 禁止重复提交, 不把上一项目详情冒充当前项目.
- Empty: 解释当前范围没有数据, 区分无项目和筛选无结果.
- Error: 保留筛选和输入, 提供重试. 401 交给模板登录流程, 403 不泄露项目内容, 409 显示可理解的冲突原因.
- Refresh: 新增/编辑后使用服务端返回数据或重新加载, 页面刷新仍保持正确路由和项目选择.
- Accessibility: 标签关联输入, 状态同时有文字与颜色, 键盘可操作, 错误不只依靠红色.
- Responsive: 桌面表格可横向滚动, 核心操作固定可见; 小屏以信息可读和表单可用为最低要求.
- Time: 统一显示时区和日期格式; 未有实际完成时间时不复制计划完成日期.

## 后续工作台

计划工作台用层次表配甘特视图, 同时显示当前版本与基线差异. Gate 面板优先显示缺失检查项和证据版本, 审核人可追溯到来源. URS 表格支持版本与追踪覆盖情况, 文档树支持受权预览. 执行看板展示来源, 更新时间, 缺件/偏差下钻. 财务页先展示口径/币种/期间/版本, 再展示四算对比, 避免跨口径误读.

AI 助手作为项目侧栏, 回答附证据引用和数据更新时间. 写操作只生成待确认的结构化草稿, 确认界面列出具体对象和字段差异, 不用聊天中的一句同意替代业务审批.

## UI 验收

首批至少验证登录后菜单, 新建/刷新/编辑, 合法结构和成员操作, 状态推进及取消, 无权限用户直达地址, 统计范围, API错误展示和重复提交. 页面截图只能证明渲染; 持久化, 权限和状态正确性须由 API/数据库及真实操作共同证明.
