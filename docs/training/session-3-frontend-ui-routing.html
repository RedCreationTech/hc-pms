1. Reagent 2 函数组件

本项目统一使用 Reagent 2 的函数组件 + React Hooks。禁止使用 reagent/atom 管理局部状态。

;; ❌ 错误 — 用 reagent/atom
(let [expanded? (r/atom false)]
  [:div {:on-click #(reset! expanded? true)} ...])

;; ✅ 正确 — 用 hooks/use-state
(let [[expanded? set-expanded!] (hooks/use-state false)]
  [:div {:on-click #(set-expanded! true)} ...])

常用 hooks：

  • hooks/use-state：局部状态
  • hooks/use-effect：副作用
  • hooks/use-callback：缓存回调
  • hooks/use-memo：缓存计算
  • hooks/use-ref：DOM 引用

src/cljs/com/ruoyi/frontend/antd.cljs 把所有用到的 Ant Design 组件转为 Reagent 组件。注意 Input.TextArea 和 Form.useForm 的获取方式：

   ["antd" :refer [App Button Card ConfigProvider DatePicker ... Form Input ... message]]
   ["@ant-design/icons" :refer [...]]))

(def app (r/adapt-react-class App))
(def button (r/adapt-react-class Button))
(def card (r/adapt-react-class Card))
(def form (r/adapt-react-class Form))
(def form-item (r/adapt-react-class (.-Item Form)))
(def form-use-form (.-useForm Form))
(def input (r/adapt-react-class Input))
(def password (r/adapt-react-class (.-Password Input)))
(def text-area (r/adapt-react-class (.-TextArea Input)))
(def select (r/adapt-react-class Select))
(def select-option (r/adapt-react-class (.-Option Select)))
(def modal (r/adapt-react-class Modal))
(def drawer (r/adapt-react-class Drawer))
(def table (r/adapt-react-class Table))

;; message 需要通过 App.useApp 获取实例
(defonce message-api (atom nil))

(defn use-app-message []
  (let [api (.useApp App)]
    (reset! message-api (.-message api))))

(defn success! [text]
  (if-let [api @message-api]
    (.success api text)
    (.success message text)))

3. 常见 Ant Design 使用规范与坑

这些约定来自 AGENTS.md 与项目实践：

注意： Ant Design 6 与 Reagent 2 混用时，以下细节非常容易踩坑。 
;; ✅ Button 的 :icon 必须是 React 元素
[antd/button {:type "primary"
              :icon (r/as-element [:> SearchOutlined])}
 "搜索"]

;; ✅ Dropdown menu 的 :label 必须用 r/as-element 包裹
{:key "user_id"
 :label (r/as-element [:div {:onClick (fn [e] ...)} [:span "用户编号"]])}

;; ✅ Drawer 的 :width 已废弃，改用 :size 或 :style
[antd/drawer {:title "用户详情" :open visible? :size "large"} ...]

;; ✅ Modal / Drawer 的 destroyOnClose 已废弃，改用 :destroyOnHidden
[antd/modal {:title "新增角色" :open visible? :destroyOnHidden true} ...]

;; ✅ Card 的 bodyStyle 已废弃，改用 :styles.body
[antd/card {:title "xxx" :styles {:body {:padding 12}}} ...]

;; ✅ 不要同时设置 :border 与 :borderColor
{:border "1px solid #1677ff"}

4. 主布局

src/cljs/com/ruoyi/frontend/pages/layout.cljs 实现了 RuoYi 风格布局：左侧 Sider、顶部 Header、Tab 栏、内容区。

(defn main-layout []
  (let [[collapsed set-collapsed!] (hooks/use-state false)
        theme-mode @(rf/subscribe [:theme/mode])
        user @(rf/subscribe [:auth/user])
        page @(rf/subscribe [:page])
        user-menus (or (seq (:menus user))
                       [{:path "dashboard" :menu_name "首页" :icon "dashboard"}])
        ;; 过滤按钮权限菜单，只保留目录 M 和菜单 C
        filtered-menus (filter-visible-menus user-menus)
        menu-items (menu->antd-items filtered-menus)]
    [:> Layout {:style {:minHeight "100vh"}}
     [:> Layout.Sider {:collapsible true
                       :collapsed collapsed
                       :onCollapse set-collapsed!
                       :theme (if (= theme-mode :dark) "dark" "light")
                       :width 220}
      [:div {:style {:height 64 ...}} (if collapsed "RY" "若依管理系统")]
      [:> Menu {:theme ... :mode "inline"
                :items menu-items
                :onClick (fn [e]
                           (let [k (.-key e)
                                 matched (router/match-route (str "/" k))
                                 page (or (:handler matched) (keyword k))]
                             (rf/dispatch [:navigate page])
                             (rf/dispatch [:tabs/add page (get labels page "页面") (get icons page)])))}]]
     [:> Layout
      [:> Layout.Header ...]
      [tab-bar]
      [:> Layout.Content {:style {:margin 24} :key (name page)}
       [error-boundary/boundary
        (case page
          :dashboard [dashboard/dashboard-page]
          :user [user/user-page]
          :role [role/role-page]
          ;; ...
          [:div "页面建设中"])]]]]))

5. Error Boundary

因为函数组件无法捕获子树渲染错误，项目用 Reagent 的 class 组件实现了一个错误边界：

(ns com.ruoyi.frontend.components.error-boundary
  (:require
   [reagent.core :as r]))

(def boundary
  (r/create-class
   {:get-initial-state
    (fn [_this] nil)
    :component-did-catch
    (fn [this error info]
      (js/console.error "ErrorBoundary caught error:" error info)
      (r/set-state this {:error error :info info}))
    :reagent-render
    (fn [child]
      (let [this (r/current-component)
            st (r/state this)]
        (if (:error st)
          (r/as-element [fallback-ui (:error st) (:info st)])
          (r/as-element child))))}))

6. 路由

本项目使用 bidi 定义路由表，并在 router.cljs 中手动管理浏览器历史：

(ns com.ruoyi.frontend.router
  (:require
   [bidi.bidi :as bidi]
   [re-frame.core :as rf]))

(def routes
  ["/" {"" :dashboard
        "dashboard" :dashboard
        "system/user" :user
        "system/role" :role
        "system/menu" :menu
        "monitor/operlog" :oper-log
        ;; ...
        }])

(defn match-route [path]
  (bidi/match-route routes path))

(defn page-path [page]
  (or (bidi/path-for routes page) "/"))

(defonce initialized? (volatile! false))

(defn init-routes! []
  (when-not @initialized?
    (.addEventListener js/window "popstate" on-popstate)
    (vreset! initialized? true)
    (let [path (.-pathname js/location)
          match (match-route path)
          page (or (:handler match) :dashboard)]
      (rf/dispatch-sync [:navigate page]))))

;; navigate! 只更新 URL，不 dispatch 事件
(defn navigate! [page]
  (when @initialized?
    (let [path (page-path page)]
      (.pushState js/history nil "" path))))

7.3 表单管理

弹窗表单使用 antd/form-use-form 创建 form 实例，通过 :onFinish 提交：

(let [visible? @(rf/subscribe [:roles/modal-visible?])
      editing @(rf/subscribe [:roles/editing])
      form-data @(rf/subscribe [:roles/form-data])
      [form] (antd/form-use-form)]
  (hooks/use-effect
   (fn []
     (when visible?
       (.setFieldsValue form (clj->js (merge {:role_sort 0 :status "0" :data_scope "1"} form-data))))
     js/undefined)
   [visible? form-data])
  [antd/modal {:title (if editing "修改角色" "新增角色")
               :open visible?
               :onOk #(.submit form)
               :onCancel #(rf/dispatch [:roles/close-modal])
               :destroyOnHidden true}
   [antd/form {:form form
               :labelCol {:span 6}
               :wrapperCol {:span 16}
               :preserve false
               :onFinish (fn [values]
                           (rf/dispatch [:roles/submit (js->clj values :keywordize-keys true)]))
               :initialValues (clj->js ...)}
    [antd/form-item {:label "角色名称" :name "role_name"
                     :rules [{:required true :message "请输入角色名称"}]}
     [antd/input {:placeholder "请输入角色名称"}]]]])
