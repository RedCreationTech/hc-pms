1. Re-frame 数据流模型

Re-frame 是 ClojureScript 的状态管理框架，核心循环如下：

  1. View 触发 (rf/dispatch [:event-id payload])
  2. Event handler 返回新的 db 或 fx map
  3. Effect handler 执行副作用（HTTP、导航、localStorage）
  4. Subscription 从 app-db 派生视图需要的数据
  5. View 订阅数据并渲染

这种单向数据流让调试变得非常清晰：任何状态变化都可追溯到一次 dispatch。

2. app-db 的扁平命名空间

打开 src/cljs/com/ruoyi/frontend/db.cljs，可以看到 default-db 是一个扁平 map，每个一级键对应一个业务域：

(def default-db
  {:page (if token :dashboard :login)
   :tabs {:items [{:key :dashboard :label "首页" :closable false}]
          :active :dashboard}
   :auth {:token token :user user :loading? false}
   :theme {:mode :light :primary-color "#1677ff" :compact? false}
   :users {:loading? false :items [] :total 0
           :query-params {} :page 1 :page-size 10
           :selected-ids [] :show-search? true
           :import-visible? false :import-loading? false :import-file nil
           :columns {:user_id {:label "用户编号" :visible? true}
                       :user_name {:label "用户名称" :visible? true}
                       ;; ...
                       }}
   :roles {:loading? false :items [] :query-params {}}
   :menus {:loading? false :items [] :tree []}
   :depts {:loading? false :items [] :tree []}
   ;; posts / dicts / configs / notices / logs ...
   })
设计原则：把服务器状态（:items、:total）和 UI 状态（:modal-visible?、:query-params、:selected-ids）放在同一个命名空间下，订阅时只需要 (rf/subscribe [:users/items]) 这样的路径。

3. 事件处理器

3.1 纯 db 事件：reg-event-db

只修改 app-db，没有副作用：

(rf/reg-event-db :auth/set-token
                 (fn [db [_ token]]
                   (assoc-in db [:auth :token] token)))

(rf/reg-event-db :users/set-list
                 (fn [db [_ data]]
                   (-> db
                       (assoc-in [:users :items] (:rows data))
                       (assoc-in [:users :total] (:total data))
                       (assoc-in [:users :loading?] false))))

3.2 带副作用的事件：reg-event-fx

返回一个 {:db new-db :effect-key effect-value} map，可同时触发多个 effect：

(rf/reg-event-fx :users/fetch
                 (fn [{:keys [db]} [_ params]]
                   {:db (assoc-in db [:users :loading?] true)
                    :api/list-users params}))

(rf/reg-event-fx :auth/login-success
                 (fn [{:keys [db]} [_ data]]
                   (let [token (:token data)]
                     (try (.setItem js/localStorage "ruoyi_token" token) (catch js/Error _))
                     {:db (-> db
                              (assoc-in [:auth :token] token)
                              (assoc-in [:auth :loading?] false))
                      :dispatch-n [[:navigate :dashboard] [:auth/fetch-info]]})))

3.3 副作用注册：reg-fx

真正的 HTTP 调用、导航、消息提示都在 reg-fx 中定义：

(rf/reg-fx :api/list-users
           (fn [params]
             (api/list-users params
                                  (fn [result]
                                    (when (= 200 (:code result))
                                      (rf/dispatch [:users/set-list (:data result)])))
                                  (fn [_]))))

4. API 层

src/cljs/com/ruoyi/frontend/api.cljs 封装了所有后端调用。核心 request 函数自动从 app-db 读取 token 并附加 Authorization: Bearer <token>：

(def api-base "/api")

(defn- get-token []
  (get-in @rf-db/app-db [:auth :token]))

(defn- request
  "发起 HTTP 请求，从 re-frame app-db 读取 token。"
  [{:keys [method uri params on-success on-error]}]
  (ajax/ajax-request
    {:method method
     :uri (str api-base uri)
     :params params
     :headers (when-let [token (get-token)]
                {"Authorization" (str "Bearer " token)})
     :format (ajax/json-request-format)
     :response-format (ajax/json-response-format {:keywords? true})
     :handler (fn [[ok result]]
                (if ok
                  (on-success result)
                  (on-error result)))}))

业务函数就是简单的 request 包装：

(defn list-users
  "获取用户列表。"
  [params on-success on-error]
  (request {:method :get :uri "/system/user" :params params
            :on-success on-success :on-error on-error}))

5. 订阅

5.1 基础订阅

(rf/reg-sub :users/items
            (fn [db _]
              (get-in db [:users :items])))

(rf/reg-sub :users/loading?
            (fn [db _]
              (get-in db [:users :loading?] false)))

5.2 参数化订阅

Re-frame 的向量订阅第二个元素开始是参数：

(rf/reg-sub :integrant/trace
            (fn [db [_ key]]
              (get-in db [:integrant :trace key])))

;; 使用
@(rf/subscribe [:integrant/trace :app.system/user-service])

5.3 派生状态

Layer-3 订阅可以基于其他订阅做计算，适合把原始数据转换成视图需要的形状：

(rf/reg-sub :users/selected-empty?
            (fn [db _]
              (empty? (get-in db [:users :selected-ids] []))))

(rf/reg-sub :users/selected-dept-id
            (fn [db _]
              (get-in db [:users :query-params :dept_id])))

6. UI 状态与服务器状态

在本项目中：

  • 服务器状态：用户列表、角色列表、字典数据等，从 API 获取，通过 :xxx/set-list 写入。
  • UI 状态：搜索框内容、当前页码、选中行、弹窗显隐等，直接存在 app-db 对应命名空间下。

不要把 UI 状态放到 reagent/atom 里，这样时间旅行调试、热重载都会失效。

7. 常见 Effect

主题持久化：写入 localStorage 同时更新 db：

(rf/reg-event-db :theme/set-mode
                 (fn [db [_ mode]]
                   (js/localStorage.setItem "rouyi-theme-mode" (name mode))
                   (assoc-in db [:theme :mode] mode)))

导航：事件触发 URL 变更，并在 :navigate 中加载对应页面数据：

(rf/reg-event-fx :navigate
                 (fn [{:keys [db]} [_ page]]
                   (let [fetch (case page
                                 :user [:users/fetch {}]
                                 :role [:roles/fetch {}]
                                 :menu [:menus/fetch]
                                 nil)
                         effects {:db (assoc db :page page)
                                  :router/navigate! page}]
                     (if fetch
                       (assoc effects :dispatch fetch)
                       effects))))

消息提示：通过 antd.cljs 中的 success! / error! 调用（下一讲详细介绍）：

(rf/reg-fx :api/create-config
           (fn [params]
             (api/create-config params
                                (fn [result]
                                  (when (= 200 (:code result))
                                    (rf/dispatch [:configs/created])
                                    (antd/success! "创建成功"))
                                  (when (not= 200 (:code result))
                                    (antd/error! (:msg result))))
                                (fn [_] (antd/error! "网络错误")))))
