1. 配置分层

本项目的配置由四层叠加：

  1. deps.edn alias 决定加载 env/dev 还是 env/prod。
  2. env/dev/clj/com/ruoyi/env.clj 设置 {:profile :dev}。
  3. src/clj/com/ruoyi/config.clj 读取 resources/system.edn。
  4. resources/system.edn 使用 Aero reader 解析环境变量与 profile。

(defmethod ig/init-key :handler/ring
  [_ {:keys [router api-path] :as opts}]
  (let [actual (ring/ring-handler ...
                {:middleware [(middleware/wrap-base opts)]})]

3. 数据库栈

数据库访问由 kit-sql-conman 提供：

  • HikariCP：连接池。
  • conman：把 HugSQL 查询绑定为 Clojure 函数。
  • next.jdbc：底层 JDBC 执行。
  • HugSQL：-- :name 标注的 .sql 文件。
-- resources/sql/system.sql
-- :name list-users :? :*
SELECT u.user_id, u.user_name, u.nick_name, u.status, d.dept_name
FROM sys_user u
LEFT JOIN sys_dept d ON u.dept_id = d.dept_id
WHERE u.del_flag = '0'
  AND (:user_name IS NULL OR INSTR(u.user_name, :user_name) > 0)
ORDER BY u.user_id
LIMIT :page_size OFFSET :offset

-- :name create-user! :! :n
INSERT INTO sys_user (user_name, nick_name, password, status, create_by, create_time)
VALUES (:user_name, :nick_name, :password, :status, :create_by, CURRENT_TIMESTAMP)

在 domain service 中通过 query-fn 调用：

(defn list-users [{:keys [query-fn]} params]
  (let [rows (query-fn :list-users filters)
        total (query-fn :count-users filters)]
    {:rows rows :total (:total total)}))

MIGRATION_DIR=migrations \

src/clj/com/ruoyi/infra/db.clj 封装了数据库类型检测与自增 ID 获取：

(defn detect-db-type [db]
  (let [product-name (.getDatabaseProductName (.getMetaData connable))]
    (cond
      (str/includes? (str/lower-case product-name) "sqlite") :sqlite
      (str/includes? (str/lower-case product-name) "mysql")  :mysql
      :else :unknown)))

(defn insert-and-get-id!
  [query-fn db insert-query params id-query id-key]
  (let [db-type (detect-db-type db)
        id-q (if (= :mysql db-type)
               (keyword (str (name id-query) "-mysql"))
               id-query)]
    (jdbc/with-transaction [tx db]
      (query-fn tx insert-query params)
      (get (query-fn tx id-q {}) id-key))))

5. 安全

src/clj/com/ruoyi/infra/security.clj 提供密码哈希与 JWT：

(def secret-key
  (or (System/getenv "JWT_SECRET")
      "rouyi-default-jwt-secret-key-change-in-production"))

(defn hash-password [plain-text]
  (hashers/derive plain-text {:alg :bcrypt+blake2b-512}))

(defn generate-token [user-id user-name roles & {:keys [exp-hours] :or {exp-hours 24}}]
  (let [claims {:user-id user-id :user-name user-name :roles roles
                :exp (+ (System/currentTimeMillis) (* exp-hours 60 60 1000))}]
    (jwt/sign claims secret-key {:alg :hs256})))

6. 在线用户

src/clj/com/ruoyi/infra/online.clj 把会话持久化到 sys_online，并提供强退黑名单：

(defonce token-blacklist
  (atom {} :validator map?))

(defn blacklist! [token exp-ms]
  (swap! token-blacklist assoc token exp-ms))

(defn blacklisted? [token]
  (contains? @token-blacklist token))

(defn register! [token user-name login-ip]
  ((query-fn) :create-online-user!
              {:session_id token :login_name user-name
               :ipaddr login-ip :status "on_line"
               :start_timestamp now :last_access_time now}))

7. 定时任务

src/clj/com/ruoyi/infra/scheduler.clj 用 Quartz 调度 sys_job 表中的任务：

(defn invoke-target-allowed? [target]
  (and (not (some #(str/includes? target %) dangerous-patterns))
       (str/starts-with? target allowed-ns-prefix)))

(defn schedule-job! [job]
  (when (and (seq (:cron_expression job))
             (invoke-target-allowed? (:invoke_target job)))
    (let [s (scheduler)
          job-detail (build-job-detail job)
          trigger (build-cron-trigger job)]
      (.scheduleJob s job-detail trigger)
      (when (= "1" (:status job))
        (.pauseJob s (job-key (:job_id job) (:job_group job)))))))

10. 构建与部署

生产构建分两步：先编译 ClojureScript，再构建 uberjar：

npx shadow-cljs release app
clojure -T:build all
java -jar target/rouyi-standalone.jar

Docker 部署可直接基于 uberjar 镜像，或把 jar 与 rouyi.db 挂载到容器内运行。
