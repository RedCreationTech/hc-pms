1. Clojure 与 ClojureScript 是什么

Clojure 是一门运行在 JVM 上的现代 Lisp 方言，强调不可变数据（immutable data）与函数式编程。ClojureScript 是 Clojure 到 JavaScript 的编译器，共享 99% 的语法与核心库，让同一门语言同时写后端与前端。

本项目的核心哲学：

  • REPL-first：优先在 REPL 中验证想法，再固化到文件。
  • 数据即代码：配置、SQL、路由、组件都是 EDN/Clojure 数据结构。
  • 不可变状态：用 assoc、update、-> 派生新值，而非原地修改。

2. 语法基础

Clojure 代码由 S-表达式 组成：(操作符 参数1 参数2 ...)。以下是实际代码中频繁出现的字面量：

;; 关键字（keyword）用于当键/标签，带冒号
:user_name  :ok  :roles

;; 符号（symbol）用于变量、函数名
user_name  list-users  +

;; 字符串与数字
"若依管理系统"   200   3.14

;; 布尔与 nil
true  false  nil

;; 调用函数：操作符在前
(+ 1 2 3)
(str "Hello, " "Clojure")

3. 核心集合

项目里所有数据结构几乎都是以下四种：

;; vector：索引访问，最常用作列表/参数序列
[1 2 3]

;; list：代码本身，也用于 cons/seq 操作
'(1 2 3)

;; map：键值对，本项目 app-db 的核心
{:user_name "admin"  :status "0"  :roles [:admin]}

;; set：去重集合
#{:user :role :menu}

4. 函数、解构与线程宏

4.1 defn 与 let

(defn greet
  "打招呼"
  [name]
  (str "你好, " name))

(let [x 10
      y 20]
  (+ x y))

4.2 解构

;; map 解构：从 request 中直接取出 identity
(defn list-users
  [{:keys [user-service]} request]
  (...))

;; vector 解构
(let [[a b & rest] [1 2 3 4]]
  [a b rest])
;; => [1 2 (3 4)]

4.3 多态、变参与匿名函数

;; 多态：按参数数量分派
(defn area
  ([r] (* 3.14 r r))
  ([w h] (* w h)))

;; 变参
(defn sum [& nums] (apply + nums))

;; 匿名函数
(fn [x] (* x x))
#(* % %)

4.4 线程宏

线程宏让数据变换从左到右阅读，本项目大量出现在事件处理与控制器中：

;; -> 把值插到第一个参数位置
(-> db
    (assoc-in [:auth :token] token)
    (assoc-in [:auth :loading?] false))

;; ->> 插到最后一个参数位置
(->> menus
     (filter visible-menu?)
     (map menu->antd-items))

;; some-> 遇到 nil 就停止
(some-> token security/parse-token :user-name)

;; cond-> 按条件添加变换
(cond-> items
  (seq search-name) (filter name-matches?)
  status (filter #(= status (:status %))))

6. 项目工具链

6.1 deps.edn

deps.edn 是 Clojure CLI 的依赖与 alias 配置。本项目定义了 :dev、:test、:build 等 alias：

{:paths   ["src/clj" "resources"]
 :deps    {org.clojure/clojure {:mvn/version "1.12.4"}
           metosin/reitit      {:mvn/version "0.10.1"}
           ;; ...
           }
 :aliases {:dev  {:extra-deps  {integrant/repl {:mvn/version "0.5.1"}}
                   :extra-paths ["env/dev/clj" "env/dev/resources" "test/clj"]}
           :test {:extra-deps  {io.github.cognitect-labs/test-runner {:git/tag "v0.5.1"}}
                   :exec-fn cognitect.test-runner.api/test}
           :build {:deps {io.github.clojure/tools.build {:mvn/version "0.10.12"}}
                   :ns-default build}}}

6.2 shadow-cljs.edn

前端构建由 shadow-cljs 负责，入口模块为 com.ruoyi.frontend.app/init：

{:source-paths ["src/cljs"]
 :dependencies [[reagent "2.0.1"]
                [re-frame "1.4.3"]
                [cljs-ajax "0.8.4"]
                [bidi "2.1.6"]
                [venantius/accountant "0.2.5"]]
 :builds
 {:app
  {:target     :browser
   :output-dir "resources/public/js"
   :asset-path "/js"
   :modules    {:app {:init-fn com.ruoyi.frontend.app/init}}
   :devtools   {:after-load com.ruoyi.frontend.app/reload}}}}}

8. 开发工作流

启动后端：

clojure -M:dev -m com.ruoyi.core

启动前端 watch（端口 3000 由后端统一服务静态资源，开发时 shadow-cljs watch 负责增量编译）：

npx shadow-cljs watch app

后端 nREPL 热重载（端口 7000）：

clj-nrepl-eval -p 7000 '(user/rd)'      ;; 重载域服务
clj-nrepl-eval -p 7000 '(user/rroutes)' ;; 重载路由定义
clj-nrepl-eval -p 7000 '(user/ra)'      ;; 重载所有命名空间
clj-nrepl-eval -p 7000 '(user/rr)'      ;; 完全重启 Integrant 系统

测试：

clojure -M:test

9. 构建与部署

;; 1. 编译前端生产包
npx shadow-cljs release app

;; 2. 构建 standalone uberjar
clojure -T:build all

;; 3. 运行
java -jar target/rouyi-standalone.jar
